# Development Roadmap

This file is intentionally lightweight.

The project is moving toward colocation and more local documentation ownership, so the canonical near-term roadmap should be taken from:

- active files in `docs/plans/`
- relevant `docs/todos/`
- subsystem-local documentation as it is introduced

## Guidance

- Treat `docs/plans/` as the main cross-project planning surface.
- Treat `docs/archive/` as the historical record for completed or superseded roadmap items.
- Do not rely on this file for detailed implementation status.
