# Active Development Plans

This directory is for active planning only.

## Rules

- Use plans for work that is still in progress or still guiding implementation.
- Prefer dated files: `YYYY_MM_DD_<topic>.md`.
- If multiple plans overlap, the newer plan wins unless one explicitly names itself the source of truth.
- Move completed, superseded, or historical plans to `docs/archive/`.
- Avoid status/build-log style docs here; keep this folder focused on executable plans.

## Related

- `docs/archive/` - completed or superseded plans
- `docs/todos/` - open task lists
- `docs/analysis/` - retrospectives, debugging, and post-mortems
