# Graphics

Generated 16x16 sprite template sheets.

- Files ending in `_template.png` are art templates.
- Files ending in `_template_rows.csv` list row ids and starter metadata.
- Columns are weight variants `w1` through `w6`.
- Each sprite cell is 16x16 pixels.
- Use transparent background in your final art layers.
- `w1` and `w2` are the expected minimum; higher weights are optional.
